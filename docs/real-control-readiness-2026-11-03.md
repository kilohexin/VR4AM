# 真机下一步准入说明（2026-11-03）

这是一份离线状态说明，不是连接或动作授权。

用户已反馈Docker真人平移方向基本可用、X/Y夹爪可用。新的VR俯仰/自转已完成Docker候选和合成WebSocket验证，真人转腕方向与手感仍待确认。不能把这两种证据合并为真机验收通过。

## 当前不可直接迁移的项目

- 新PVAT执行器仅认官方本机Docker，连接固定127.0.0.1模拟SDK，通过docker exec和容器内部Lua3010执行。没有新真机选择器，不能只改IP绕过准入。
- 工具/准备位与FK模型：Docker使用独立零TCP、仿真准备位和原厂核对后的本地模型；真机必须新读核对实际工具、标定和保存姿态，不复制仿真模型。
- X/Y在Docker更新本地虚拟夹爪，允许并行，无接触物理。真实夹爪的反馈、开合方向、初始化、力及与机械臂并行尚未验收。
- 历史真实读取超时和运动中stop_unverified仍保留；仿真停止门槛、帧窗口、名义速度不自动迁入。
- 官方Docker内部机器人服务已出现atomic_log的64项数组越界panic；当前没有修复原厂二进制。一次新鲜实例验证通过不能证明长会话稳定，也不能断言真机版本同样存在或不存在此问题。

## 推荐下一轮顺序

1. 离线完成新执行器的真机预览/身份绑定与单次预算，保持默认零连接；当前版本先不开放完整真机VR抓取。
2. 操作者到场后，根据当天地址、IDLE/PAUSED、工具、姿态和其它控制状态生成新的只读范围并获明确授权，只做新读核对。
3. 核对通过后另行给出具体空载单次动作范围，先网页准备/小步自然结束、松手余量及异常退出。未经确认的停止不得被后续静止样本清除。
4. 真实夹爪空载验证独立进行；通过后才扩大到VR平移/俯仰/自转，最后讨论真实负载和接触抓取。

范围须绑定当时源码、配置、SDK与现场条件。Docker测试授权不等于真机授权；当前未生成真机执行凭据、未连接真机。
