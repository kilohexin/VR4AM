# 可选的有界观察等待窗口

2026-10-09，Asia/Shanghai。接续 [延迟注入实验](pvat-delay-injection-2026-10-09.md)。本轮离线实现调度候选，**默认关闭，生产调用与真机入口没有启用**；没有新 SDK 连接或现场动作。

## 已实现

`RealLebaiAdapter` 增加构造参数 `observer_wait_s=0.0`，只允许 0～0.020 秒。没有新增网页开关、配置字段或自动开启路径；非零值仅供明确选择的离线构造使用。

有效运动 handler 持有独立 lease。普通 `get_state` 在健康且不处于停止/断开入口时，可以等待当前窗口释放一次；预算耗尽后照常执行完整新状态读取，既不复用缓存，也不取消运动。返回、错误、超时和取消都在运动 wrapper 的 finally 释放自己的 lease。

停止、断开与停止未确认锁存/收尾入口释放旧窗口；已知锁存故障、stop_lock 持有或正在断开时，新观察不进入窗口。等待后重新检查 pump fault，避免在等待期间出现的失败被忽略。

运动快照、停止验证及只读停止尾段直接调用 `_read_snapshot`，不经过这一窗口。200 ms 停止规则、新鲜度、PVAT 时域/速度/频率和 SDK 锁保持原逻辑。

观察额外等待的开始/结束和预算写入独立 QPC 诊断，仍 `alignment_verified=false`。诊断中的嵌套字典使用独立复制，避免记录回调改写另一份证据。

## 竞态修复

针对“停止释放旧窗口后，立即开始新窗口”的回归，初版复现了新任务重新关闭旧 Event。修复为释放旧 Event 后创建新的 Event；旧等待者继续看到已释放的对象。旧 lease 的 finally 不能释放新的有效 lease，重复结束也不影响其它重叠任务。

## 离线验证范围

- 预算范围、默认关闭、单次预算到期、观察取消不结束运动。
- 多 lease、停止释放后新 lease、旧任务延迟收尾。
- 停止/故障锁存/断开入口唤醒，以及 urgent get_state 绕过窗口。
- 运动、停止验证、停止尾段的完整快照读取不被窗口挡住。
- SDK 正常返回、超时、异常、取消的运动退出均释放窗口。
- 人工固定“预算尚未到期”的端到端调度：观察在运动结束后仍完成全部安全字段读取；超时回退由另一个实际窗口用例覆盖。

首次缺模块测试明确失败；旧 Event 被重关的回归也先失败再修复。一次综合回归的端到端用例失败发生在测试 cleanup：断开后的 stop 写入被测试桩错误拒绝，已在断开前恢复原读取函数。该错误未通过放宽生产停止路径处理。

独立静态复核未发现新增可操作的 P0–P2。现场配置、原始会话与抓包不上传，用户已有项目总结文件保留。

## 当前限制与下一步

20 ms 是向 asyncio 请求的额外等待预算，不是实时硬保证，也不包含之后的 SDK 锁等待和完整读取时间。未被读取的新物理故障仍可能在该预算之后才被观察；本轮没有证明现场允许这项延后。已排队的观察和预算到期后的观察仍可能插入运动两段锁之间。

因此本实现不承诺发点永不被插队、总周期更短或停止更快。默认 0 的现有生产路径保持关闭；不会仅凭离线通过开启真机。下一步对候选做可重复的离线负载比较，量化观察延后、完整周期和发点间隔，再决定是否为单次诊断提供可审查的启用入口。

运动停止约 613 ms 回复仍未解决，连续 VR 与真实 Trigger 抓取验收尚未完成。源文件改变后旧 runtime 绑定不能用于新版本；任何新的真机连接/动作仍需独立明确范围及现场条件。暂不推送。
