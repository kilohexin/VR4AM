## 问题 1：临时 Windows 入口没有指定 JSON 编码

原 `admin-broker.ps1` 使用 Windows PowerShell 默认编码读取无 BOM 的 UTF-8 材料，中文字符串发生损坏，JSON 解析报错。本机针对原文件的默认读取明确复现失败；使用 `Get-Content -Encoding UTF8` 后，完整绑定字段解析通过。

修正后的临时入口检查旧进程确实在运动启动器前结束、目标目录尚不存在、批准材料/启动脚本 SHA-256 不变，并显式读取 UTF-8。旧失败材料与进程记录保留，没有覆盖。此项修正仅涉及本机临时启动材料，没有改变机器人控制链路。

## 问题 2：Pktmon 名称列显示截断

本轮生成的完整名称 `VR4ArmMotionStop_8a52ed2d299e` 长 28 字符，实际列表显示 `VR4ArmMotionStop_8a52ed2...`。此前 26 字符的只读名称完整显示。原 FakeNative 直接回显完整名称，离线测试因此遗漏了本机列表显示行为。
