## 3. Touch Plus 输入与相对位姿

保持慢速、小范围动作，并由旁观者同时观察状态牌和仿真机械臂。以下均为原厂 Touch Plus **右手柄**测试。

### 平移六方向

- [ ] 解锁并按住 Grip 后，右手柄向左（−X）移动，仿真 TCP 沿对应方向平滑移动。
- [ ] 解锁并按住 Grip 后，右手柄向右（+X）移动，仿真 TCP 沿对应方向平滑移动。
- [ ] 解锁并按住 Grip 后，右手柄向下（−Y）移动，仿真 TCP 沿对应方向平滑移动。
- [ ] 解锁并按住 Grip 后，右手柄向上（+Y）移动，仿真 TCP 沿对应方向平滑移动。
- [ ] 解锁并按住 Grip 后，右手柄向前（−Z）移动，仿真 TCP 沿对应方向平滑移动。
- [ ] 解锁并按住 Grip 后，右手柄向后（+Z）移动，仿真 TCP 沿对应方向平滑移动。

### Grip 锚点与姿态

- [ ] Grip 从松开到按下时以当前手柄/仿真 TCP 位姿建立相对锚点，TCP 无瞬时跳变。
- [ ] 松开 Grip、移动手柄到另一位置再按 Grip，重新锚定时 TCP 无跳变。
- [ ] 按住 Grip 做正/反 roll，仿真 TCP 姿态方向与手柄相对旋转一致且连续。
- [ ] 按住 Grip 做正/反 pitch，仿真 TCP 姿态方向与手柄相对旋转一致且连续。
- [ ] 按住 Grip 做正/反 yaw，仿真 TCP 姿态方向与手柄相对旋转一致且连续。

### Trigger、A/B 与状态牌

- [ ] Trigger 从 0 缓慢增加到 1 再回到 0，HUD 数值和仿真夹爪动画连续跟随，无越界或反向跳变。
- [ ] 进入 VR 后松开 Grip/A/B，按一次 A 只发送一次解锁请求，并在后端确认前显示“解锁中”、确认后显示“已解锁”。
- [ ] 长按 A 不重复解锁；A 在 Grip 按下时不能解锁；松开 Grip 和 A 后重新按 A 才能发起新请求。
- [ ] A 与 B 同帧按下时 B 优先，系统停止/解除使能而不是解锁。
- [ ] B 单次按下立即显示“已停止”并解除使能；长按 B 不重复发送，松开再按才产生新停止请求。
- [ ] 状态牌在头显内文字清晰、未遮挡机械臂/工作区，并正确显示所有可触发状态。
- [ ] 对未识别 profile、按钮不足或等价测试夹具，显示“手柄不受支持 / 当前配置不支持 A/B 安全控制”，且保持锁定、无猜测式回退。

## 4. 停止路径与重新使能门禁

每个项目都应从已解锁/运动状态单独开始。事件触发后必须确认运动停止并锁定；恢复后持续按住 A、B 或 Grip 不得自动解锁，必须全部松开，再重新按 A 并等待后端确认。

- [ ] 松开 Grip：立即停止运动；重新按 Grip 只在仍已解锁时从新锚点继续，无跳变。
- [ ] 右手柄追踪丢失：立即停止并锁定；追踪恢复后必须完成全松开和 A 重新按下。
- [ ] Quest XR 会话可见性变为 `hidden` 或 `visible-blurred`：立即停止并锁定；恢复后必须重新使能。（桌面 `window blur` 不是独立的 Quest 真机项目。）
- [ ] WebSocket 关闭或网络断开：立即停止并锁定；重连后保持锁定，必须重新使能。
- [ ] XR 会话 `end` / 主动退出 VR：立即停止并锁定；进入新会话后必须重新使能。
- [ ] 刷新或关闭页面：立即走本地停止路径；重新打开并连接后保持锁定，必须重新使能。
- [ ] 按 B：立即停止并进入 `DISARMED`；松开 Grip/A/B 后重新按 A 才可再次使能。
