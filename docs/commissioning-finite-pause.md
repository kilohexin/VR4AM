# 单次有限段暂停诊断

入口：`scripts/real_robot_finite_pause.py`。这是独立诊断，默认只生成预览；软件开发批准不包含真机连接或动作授权。网页和 VR 的默认停止方式仍是原 `stop_move`。

## 固定范围

| 项目 | 限制 |
| --- | --- |
| 连接 | 一次，目标必须为配置中的私有 IPv4 字面地址 |
| 运动 | 预检通过后最多一次基座 +Z 0.05 mm PVAT，参考时长 10–80 ms，末速度/加速度为零 |
| 数学核对 | 最多 IK1/FK4，反馈 FK 提前计算、其余 FK 并发，运动快照六字段并发 |
| 准备位 | 使用已有配置参考，关节比对容差 0.001 rad，不自动移动回位 |
| 工具、工作区和限速 | 沿用被哈希绑定的配置；关节请求速度不超过 0.05 rad/s、加速度不超过 0.2 rad/s² |
| 运动时序 | QPC 事件循环，同一高精度时钟；100 ms 准入和 60 ms PVAT 回复上限 |
| 终止 | 最多一次 `pause_move`；已准入后数学失败、撤权或取消也只使用这一次预留清理 |
| 原验证 | 200 ms RPC 回复、300 ms 连续稳定、500 ms 验证窗口，不延长期限 |
| 尾段 | 两秒只读观察窗口，窗口内发起的读取保留其正常预算；PAUSED 必须有明确 FINISHED 任务证据，任何尾段读取失败都不能整体通过 |
| 禁止项 | 恢复、第二目标、停止回退、重试、Home、准备位移动、夹爪、复位和抓包 |

机械臂暂停后可能保留旧轨迹。不要点击“恢复”；任何额外收尾须另行决定。预览不会保留连接或发送停止命令。

## 预览与执行隔离

1. 准备现场配置和新的 `.tmp` 输出路径，仅运行默认预览。配置必须明确使用 0.05 mm 步长；入口拒绝其它步长，不替用户改配置。
2. 预览包含独立范围名 `one_finite_z50um_window_and_reserved_cleanup_pause`、允许的实际写入方法、源码/SDK及配置哈希、固定配置选择和独立确认语句。没有有效期的预览不能执行。
3. 新真机尝试须用户确认当前地址、电源/IDLE/准备位、目视静止、空载净空、在旁观察及急停、无其它控制和工具模型未变，并明确批准这一次范围。
4. 获批后才能生成新的十分钟启动有效材料，逐项核对；旧停止预览、旧暂停多段预览或已消耗的授权不能复用。
5. 执行前及阶段边界进行完整 SHA 校验；实际 PVAT 入口复查已加载运行时的文件身份/元数据、配置和期限。该策略不能识别刻意保留元数据的篡改，沿用已有策略。
6. 输出路径使用排他创建，一旦进入尝试即消耗，连接失败或取消也不能在同一路径重跑。未知结果保留锁存，不根据迟到回执或后来 IDLE 自动清除。

入口以独立进程使用，仍要求项目 `.venv`。程序退出或本机无 RPC 连接不能证明控制器释放了全部资源，也不能证明机械臂物理停稳。

## 离线验证边界

测试通过显式工厂注入进程内 Fake。工厂是可信依赖注入契约，不构成网络沙箱；Fake 结果不代表控制器行为。本轮还使用真实仓库的完整源码/SDK哈希及元数据检查运行该流程，未导入原生 SDK、未连接机器人。

`termination_method`、`pause_entries`、`stop_entries` 分别报告实际方法及次数；`stop_confirmed` 是通用停止事务的判据结果，暂停路径并不因此变成一次 `stop_move`。`hardware_verified` 保持 false。现场停止可靠性、实际位移、速度反馈和持续网页/VR操纵仍需独立验收。
