## 7. Quest 遥操作

### 7.1 平移

- [ ] Grip 零位锁定后，手柄前伸，TCP 沿预期“前”方向移动。
- [ ] 手柄后移、左移、右移、上移、下移均与直觉一致。
- [ ] 松开 Grip 后停止；重新按住时从当前 TCP 重锚定且无跳变。
- [ ] 平移比例符合配置，边界提示可理解且允许安全退回。

### 7.2 姿态

- [ ] 初始夹爪为左右夹爪、双目摄像头一侧朝上。
- [ ] 手柄 roll 对应夹爪 roll。
- [ ] 手柄 pitch 对应夹爪 pitch。
- [ ] 手柄 yaw 对应夹爪 yaw。
- [ ] 姿态边界只保持最后安全目标，不造成连续穿模或突跳。

### 7.3 夹取

- [ ] Trigger 开合方向正确。
- [ ] 成功抓取一个轻质物体。
- [ ] 成功移动并释放轻质物体。
- [ ] 抓取/释放过程中未触发意外 TCP 或关节运动。

## 8. 失联与故障注入

逐项测试前确保观察员准备好急停：

- [ ] Grip 松开：立即停止并锁定。
- [ ] Quest 页面关闭/刷新：停止并锁定。
- [ ] XR 可见性变为 hidden/visible-blurred：停止并锁定。
- [ ] 右手柄跟踪丢失：停止并锁定。
- [ ] Wi-Fi 断开：停止并锁定。
- [ ] WebSocket 断开：停止并锁定。
- [ ] 后端正常关闭：执行停止、断连并关闭日志。
- [ ] 关键日志不可用：不阻断物理 stop，并进入 `recording_unavailable` 故障。
- [ ] 恢复连接后不会自动重新 ACTIVE，必须重新松开按键、预检和解锁。
