# 原厂 Docker 接入与功能验证进度

更新：2026-10-28。仅操作本机官方 Docker，未访问真实机器人，未推送。

## 已实现

- 独立 `LEBAI_DOCKER / finite_position_docker` 运行方式；固定 SDK `127.0.0.1:3030`，核对本机 Docker 上下文、官方镜像、启动入口、端口和无设备/挂载。拒绝远程上下文及真实端口，不回退。
- `scripts/run_lmaster_docker.py` 默认只预览，`--run` 启动网页。初始 STOP 可启动虚拟控制器；PAUSED 等非预期状态拒绝。初始化纳入持久调用所有权，取消/超时未知结果隔离，禁止并发初始化。
- 解锁与准备分开；方向输入、升降、工具俯仰共用有限目标链。正常松开完成当前目标，单步平移 2 mm、俯仰 0.5°。
- 桌面输入独立于 WebGL 渲染采样；XR 接管时暂停桌面采样，退出及销毁正确清理。
- 显示反馈延迟时释放有限手势，避免无意义地重新解锁；恢复反馈后不重放旧手势，VR 要求重新松开/握持。待回执夹爪跨反馈间隔也不重放 Trigger 变化。
- 任务 FINISHED 仅作为同一连接/代次/绑定/任务、同一步的终态证据复用；关节、速度、TCP 等反馈持续新读，到位仍须满足稳定观察。停止、未知调用和新步骤使复用失效。
- 已完成动作后的 Docker 页面关闭可等待正在读取的调用在原期限内结束，再执行原断连停止；不把取消本地读取当作停止证明。
- Docker 故障或未知调用锁存后拒绝新会话，网页停止自动重连，防止重复 SDK 访问和日志风暴。
