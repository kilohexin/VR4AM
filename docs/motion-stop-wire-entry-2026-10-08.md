# 真机 VR 前置验证：单次受限平移与停止收发入口

2026-10-08，Asia/Shanghai。接续 [独立诊断计时](diagnostic-performance-clock-2026-10-08.md)。本轮仅离线开发、Fake SDK 定向测试和 Windows 隔离替身验证，没有连接机器人、现场采集、运动或停止命令。真机 VR 优先，物理抓取仿真后置；暂不推送。

## 本轮实现

新增 `scripts/motion_stop_wire_capture.py` 与专用子入口 `scripts/real_robot_wire_stop.py`，复用已有 commissioning/RobotControl/PVAT/停止事务，不创建第二条控制链路。父入口默认只输出离线预览；共享 Windows 启动器通过显式 `-MotionStop` 选择这一固定入口，默认仍不执行。

| 边界 | 固定范围 |
| --- | --- |
| 动作 | 单次 +Z 3 mm，观测到权威运动证据后触发已有早停 |
| 停止后观测 | 2 秒已有只读诊断尾段；不增加新的机器人写入种类 |
| TCP 软件限值 | 速度 ≤0.005 m/s、加速度 ≤0.02 m/s²、单步 ≤0.0005 m |
| 旋转软件限值 | 速度 ≤0.05 rad/s、加速度 ≤0.1 rad/s²、单步 ≤0.2° |
| 关节软件限值 | 速度 ≤0.05 rad/s、加速度 ≤0.2 rad/s² |
| 捕获 | 单个明确组件、TCP 3031、名义 30 秒预算、本轮唯一筛选器 |
| 排除的动作 | 自动准备位姿、Home、复位、自动 stop_sys、重试 |

这些是配置与软件调用约束，不是实际机械速度验收。沿用早停判据；若在目标窗口前没有观测到运动，不把完成平移当作运动中停止成功。没有改变原 200 ms、stop_unverified 或相关门禁。

执行要求独立现场授权、管理员环境、确认字符串、完整批准预览与 SHA-256、UTC 有效期、配置哈希及已审工具基线。批准预览绑定动作、源码、配置、组件、端口、名义预算、基线哈希及唯一输出目录；运行源码包含共享 PowerShell 入口。代码、配置、目录或基线改变需重新准备材料。

父入口拒绝非空筛选器或非零既有 RPC 连接；在捕获前与子进程前复核输入、有效期与捕获归属。子入口在实际 SDK factory 前复核本轮捕获凭据、授权与本地连接表，先独占创建 admission 文件再尝试一次连接；失败后同一目录不能再连接。初始化等待之后，在 Grip 激活输入前及首个平移目标发布前再次复核；授权在夹爪读取或初始状态读取等待中失效会阻止运动输入。启动检查后原控制流程继续使用既有安全机制；这里不声称授权文件与 SDK 写入之间具备原子性。

## 故障与收尾

父入口记录 `motion_start_attempted`、进程是否退出、退出码、timeout 与未完成标志。运动子进程未退出、非零退出、等待错误或启动后状态未知时，保守设置 `robot_stop_unknown`/`operator_attention_required`，即时提示现场处理、禁止重试。进程退出不能作为机械臂已停止证据。

Windows 执行分支保留隐藏子进程的 stdout/stderr，同时每 100 ms 检查独立 `attention-required.json` 告警文件，并以 stdout 中 `VR4ARM_STOP_UNKNOWN` 为兜底，立即向调用方输出和刷新提示；不会等到 ETL 转换完成才通知。原始日志保留；退出码通过保留进程句柄及等待退出获取。不会强制 kill/terminate 运动客户端。

只停止仍能核对为本轮所属的捕获，并在 `pktmon stop` 返回后复核已审 idle 指纹。归属改变或状态不明时标记人工处理，不停止外来捕获、不全局删除筛选器。原 ETL 与 PCAP 副本保留；动作失败时仍尝试保存已结束的捕获证据。

`acquisition_complete` 要求子进程正常完成、本轮捕获停止、转换成功、输入保持等条件；false 不意味着已保存的失败证据被丢弃。筛选器仍待人工清理时 `complete=false`。`hardware_stop_verified=false` 始终保留，任何这些标志都不替代现场停止验收。

30 秒与 32 MB 参数不是绝对的机器人执行时间或磁盘硬上限；客户端等待超时不会靠杀进程制造“停了”的结论。既有真实捕获的第一 ETL 达到 144 MiB，仍须考虑磁盘与人工收尾。无线驱动封装仍需下一步离线核对，入口转换成功不等于任意新包已能解释。

## 离线验证

新增边界用例覆盖默认无 Native/无捕获输出、唯一动作与连接、配置限值、源码/批准/有效期/目录变化、外来捕获与筛选器、进程未退出/非零退出/异常、停止捕获后的复核、无强制终止、捕获凭据及授权在真实 smoke 等待路径失效。缺陷用例先红后绿；两个等待点最初仍提交目标并最终 motion timeout，修正后阻止运动输入。
