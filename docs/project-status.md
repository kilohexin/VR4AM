## 11月1日：网页俯仰方向与短步速度估算

按操作者反馈交换网页抬头/低头按钮的俯仰符号，去掉不直观的正负号；VR手柄坐标映射未据此盲目翻转。Docker规划采用短距离静止起止的三角速度峰值 min(v, sqrt(a*d)) 作为实际请求速度，再执行原J/Jdot速率审计，避免用无法达到的完整速度上限导致反复将加速度除以4。共享默认和真实入口不启用此优化，未提高保护上限，也没有真机提速验证。

后端相关74项、前端42项、TypeScript和构建通过。官方Docker准备、X双向及Y正向各16mm通过；随后Y反向松手阶段出现 position_feedback_expired，整链失败，保留日志。因此速度优化仍是Docker候选，不声明稳定性完成或固定提速倍数。

长按断续仍未解决：当前movej每步r=0，逐步自然到位和至少200ms稳定检查后续发。真正连续轨迹需要独立实现受限续接和松手收尾，不能用提高速度上限或扩大步长冒充；也不能直接将Docker候选用于真机。
