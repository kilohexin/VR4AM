# 持按速度续接：离线协议阶段结果

日期：2026-10-19。执行依据：[已批准计划](superpowers/plans/2026-10-19-native-jog-held-input-offline.md)，沿用当前会话直接实施；未授权或执行新的真机连接、命令或网页控制。

## 交付及关键限制

已增加最新输入门、仅loopback的续接适配器及原生SDK自有回环。输入驱动速度包续接、未发送输入替换、撤权与原停止的**离线协议闭环**通过验证。原单次候选、真实地址入口、网页/VR默认路径及现场配置没有改动。

**现有ModelJogRegionGuard只接受零报告起始速度/加速度及准备位附近的小偏差，本轮保留这一限制。** 因此合成MOVING状态/己方任务ID配合零速反馈，仅用于检验控制协议；遇到非零速度反馈仍会拒绝。这不是动态运动模型或持续真机准入，不能声称已经解决真机跟随、关节动态约束、制动余量或历史停止失败。

## 实现

- `native_jog_stream_gate.py`：待发队列容量1，严格新序号/不倒退时间，输入消费一次，最多一个在途包。SDK入口前必须仍是最新输入；进入后仍按该包的原输入截止收尾，后来的输入不能续租它。每会话最多10次实际入口/1秒，第10包可以正常返回后停止，第11包禁止，撤权后不重建会话。
- `native_jog_stream_candidate.py`：仅字面127.0.0.1、显式工厂、Fake标签及严格绑定的现有模型守卫。工厂属于可信依赖，不是网络沙箱。首次仍需原完整IDLE预检，续接只接受同连接/代次已知返回的己方运动ID；外部ID、PAUSED、工具/模型/配置变化及未知结果拒绝，不能改写反馈状态来过预检。
- 原普通快照在MOVING时不查任务状态，所以候选另用读取所有权管理一次50 ms任务状态查询；不伪造或安装改写后的快照，取消/迟到查询保留未知隔离。
- 独立截止监听只监听真实输入的固定期限，不生成输入或缓存心跳；没有后续API调用也能撤权并发起原停止。松开、过期和故障共享唯一原stop_move事务，原100/60 ms及200/300/500 ms和全部锁存不变。

## 定向测试

输入门19项、适配器27项、脚本27项新增测试。按任务观察缺失实现的RED后实现；另5项冻结对象损坏输入曾未被拒绝，补充边界重校验后通过，不修改原输入对象。任务1含旧速度包测试共61项通过；任务2含原单次、所有权及停止回归共150项通过。

适配器首轮3项失败定位为普通快照没有MOVING任务状态证据，补充上述有所有权查询后通过。一次虚拟时钟过期用例采用固定130 ms墙钟睡眠时未观察到异步停止调度完成，精确复跑通过；改为有界等待实际停止写入事件，产品100 ms输入截止没有改变。这不是硬实时调度验收。所有早期失败仍记入执行台账。

作者复核发现：已消费输入刚好到期时，新输入可能抢在截止监听前延长会话。新增两项RED后修复为所有门API先检查既有输入截止；过期后永久关闭，新输入不能复活会话。

独立复核发现两项P2，均先观察RED再修复：

1. 更新输入恰好在原生所有权任务创建时到来，原包尚未进入，却被所有权层转换为超时并关闭会话。现在仅在明确未进入、无未知调用、所有权拒绝原因是撤权且完整重新校验通过时消费被替换旧包。配置损坏、过期、快照变化及真正撤权仍关闭会话，不能借替换掩盖其它失败。
2. 冻结对象被强制改成列表时，旧签名会引用同一可变列表。现在签名递归独立捕获内容和类型，并与重新构造的规范包比较；修改方向不能绕过输入序号与入口校验。

还补充了己方任务状态查询期间并发快照、显式取消及取消后晚到结果的隔离测试。独立复核相关七项通过，确认两项P2已解决，无新P1/P2；不涉及硬件或动态停止验收。没有遗留的复核小项。
