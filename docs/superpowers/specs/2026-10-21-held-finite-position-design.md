日期：2026-10-21。状态：用户已认可书面设计并要求继续实现计划；尚未实现或授权真机访问。

后续已实现离线候选。2026-10-21用户再次要求加速并接受停止延迟，批准沿有限目标自然到位主线推进；发送前契约调整为“规划最多1秒，随后重新读取并严格比对同一起点，实际入口仍要求新反馈和最新真实长按输入小于100 ms”。不再要求数学计算及其最初输入帧在100 ms内完成；单次固定目标使用其独立授权截止，不伪装成长按输入。正常松开不例行停止，异常规则不变。实现、未通过项和现场边界见 [本轮结果](../../finite-position-revalidation-2026-10-21.md)。以下原设计保留，涉及原始起点/输入年龄的段落以此补充为准。

## 1. 要交付的操作

用户要用现有网页摇杆控制机械臂接近并抓取轻物体，随后将同一后端控制接到 VR。用户已接受：长按自动连续生成有限小目标；松开不追加目标，已经发送的小段自然到位后停，因此会有剩余位移和等待。仍是长按操作，不改为每次点击走一步，也不要求预先示教抓取点。

本设计先完成 XYZ 平移这一条链。网页保留独立的“解锁”“进入准备姿态”，解锁本身不运动；准备到位才允许操纵。渐进开合和自转现有界面保留，各自的真机验收状态不能随平移自动变成通过。物理抓取仿真不属于本阶段。

正常松开与异常停止成为不同的控制事件。这是控制契约变更，不能通过修改一个 stop 超时值完成。

## 2. 选择及证据

| 路线 | 作用及代价 | 本阶段选择 |
| --- | --- | --- |
| 原厂 IK 求关节目标，再单次 movej，自然到位后才下一步 | 复用已验证的准备位 SDK 能力、任务查询；TCP 路径不保证直线，每段会停顿；仍需要 IK/FK 准入 | 首选离线候选 |
| 单次原厂 movel 直线到位 | 更贴近平移意图；本项目异步桥接、控制器行为及关节约束尚未验收 | 不同时引入，避免两条新通路 |
| 继续 speedl／PVAT，正常松开调用停止 | 保持原手感；仍依赖当前未通过的运动中停止确认 | 保留原模式，不作为新候选的正常结束机制 |

10 月 20 日独立回准备位的一次 movej 已正常返回，任务、到位及尾段通过，未调用 stop_move；这是复用依据，**不是连续小步或物理停止验收**。见 [回位证据](../../ready-return-site-2026-10-20.md)。

10 月 21 日 speedl 的发送前核验通过，原生调用正常返回，随后 stop_move 超时；停止锁等待约 0.036 ms。现有证据不支持继续通过缩短文件扫描来解决这次停止等待。见 [现场结果](../../native-jog-precheck-site-2026-10-21.md)。

源码依据：`robots/lebai_adapter.py` 的 `prepare`、`_move_to_joint_pose`、原厂 IK 调用和停止事务；`commissioning/ready_return.py` 的单次所有权、运动 ID 与结果未知处理；`control/segmented_strategy.py` 的最新输入策略。当前 `SegmentedLebaiAdapter` 实际仍发送 PVAT，不能换个名称当作本方案。

本机 SDK 存根有 movej、movel、get_motion_state 签名。存根及成功回位不保证新小步的 TCP 路径、实际限速或松开残余量。

## 3. 数据与所有权

新增独立的有限位置候选，不直接修改旧 PVAT 策略或把 prepare 的配置目标替换成任意点。分为三个职责：

1. **输入门**：保存最新方向、强度、序号、接收时间和会话代次；不保存未来点队列。平面与升降合成后按向量模限幅。
2. **单步规划与执行**：从本步新反馈生成 TCP 目标，调用原厂 IK 并核验，最多发送一次 movej，跟踪唯一运动 ID。控制器 IK 是目标来源，不能直接把视觉模型的数值 IK 用于真机。
3. **会话控制**：只有本步完成并稳定后，才从新反馈和最新持按输入规划下一步；显式松开则结束续发。状态和日志提供给现有网页／VR。

准备／Home／平移／自转／夹爪共享写入仲裁；初版候选平移期间禁止插入另一类动作。无并行运动写入、圆滑拼接或预先排队下一步，movej 的 t=0、r=0，与已验证回位的调用形式一致；请求速度／加速度由配置限幅。

每步绑定连接实例、配置／工具身份、会话代次、输入序号、起点快照、目标、运动 ID、固定规划与完成截止。迟到的 IK、读取、SDK 回执或旧代次结果不能创建下一步。

候选使用独立的输入意图／释放事件，带单调序号和代次；优先处理释放，拒绝更旧的持按消息。不能将现有通用 stop 请求重新解释成正常松开。已有网页／VR 模式继续保持原处理，新行为仅在显式选择的离线候选中启用。

## 4. 松开与异常的明确分界

| 事件 | 未进入原生运动调用 | 已进入原生运动调用 |
| --- | --- | --- |
| 显式正常松开／摇杆回中 | 撤销本步，不发送；清空未来意图 | 进入“正在完成当前小步”，继续只读监控，到位后停止续发；不为这次正常松开调用 stop_move |
| 持按中改方向 | 作废未发送的旧规划，下一次按最新方向重新规划 | 当前目标不改变；自然到位后才按最新方向规划，不积压反向目标 |
| 停止按钮／B、输入过期、失焦隐藏、断线、撤权、工具变化、异常反馈 | 撤销；只有能证明零写入且无前段义务时才可零停止结束 | 取消续发，走原唯一停止事务；保留 stop_unverified 和未知结果隔离 |
| 本步到位超时、SDK 结果未知或运动 ID 不合法 | 不允许重试或换通路 | 原异常停止及锁存，晚返结果不能恢复续发 |

正常松开只撤销“新运动写入许可”，不撤销已发送目标的只读监控所有权；否则会再次把正常松开变成取消在途事务。紧急／异常撤权仍覆盖整个会话。已松开后再次持按也不得穿过未完成步；必须先完成该步并接受一个新的有效输入。

100 ms 输入有效期只限制创建／发送新目标，持按端按现有真实输入机制更新；不得合成心跳延长旧输入。明确松开已被接受后，允许仅监控该步到原固定完成截止，不因为此时没有持按输入又发起异常停止。若没有收到松开而输入自行过期，按异常处理。

## 5. 规划与到位判据

每步以反馈 TCP 为起点，固定姿态，位移与摇杆强度成比例。新候选离线默认最大步长 **0.5 mm**，不是已经批准或测得的物理残余上界。斜向合成仍最多 0.5 mm，不是每轴各走 0.5 mm；目标绝不从累计鼠标／手柄偏移中不断追赶。

离线会话最多 10 步／10 秒，完成超时默认每步 2 秒，正常稳定观察至少 3 组且跨越 100 ms；这些是新候选的可评估参数，不能作为真机授权。先评估这种有停顿的操作速度能否满足抓取，再考虑改步长或稳定观察，不能隐含提高参数。

会话截止从首次准入固定计算；已在途目标也不得跨过它继续正常监控，截止时走异常停止。零强度等同正常松开；极小非零输入若无法满足反馈分辨率和进度判据则明确 HOLD，不积累成更大的补偿目标。准备位的 0.3 秒稳定时间保持原样，不替换成小步候选的 100 ms。

新步发送前必须：

- 保持原预检、关节软限位、工具匹配、奇异风险、配置及文件身份检查；有未知结果／故障锁存则拒绝。
- 起点必须是己方上步已自然完成的静止状态，或本会话首次通过的 IDLE；不全局接受其它 MOVING 任务。
- IK 使用当前实际关节为种子，拒绝不连续分支、不可达及关节跳变。使用原厂 FK 核对反馈、终点和关节插值中间点；通过已有检查不等于控制器实际轨迹证明。
- 发送前原 100 ms 反馈新鲜度不放宽；数学结果必须绑定同一关节／工具输入。不符合则零写入拒绝；原生调用前重查，不能只在开始规划时查。
- 保留配置的关节与 TCP 速度、加速度及绝对工作区约束；不得把 PVAT 的 80 ms 参考套到 movej。请求关节限速不能直接证明 TCP 限速。离线规划须检查关节路径 FK／雅可比得到的 TCP 约束，并显式记录模型与采样边界；缺少实际轨迹证据时拒绝进入连续真机模式。
- 工作区固定于批准参考，不随每次小步移动中心；原 ±5／±10 mm 历史诊断范围不自动成为新模式的可动范围。关节插值采样不能证明无碰撞或 TCP 完全走直线。

正常到位必须同时满足：本次已知运动 ID 为 FINISHED、机器人 IDLE、无其它任务／故障、实际关节及 TCP 接近目标、速度反馈满足稳定要求，且连续稳定观察成立。查询报错、PAUSED、任务 RUNNING 或目标反馈接近均不能算到位。

特别防止“小步小于旧容差，因此未运动也成功”：离线默认终点 TCP 误差最多为本步长度的 20%，沿请求方向实际进度至少为本步的 70%，横向偏差最多为本步的 20%；姿态仍须匹配。不因关节误差落在旧 0.001 rad 准备位容差内就完成该步。零进度、反向、侧向偏离、反馈卡住必须有独立失败原因。若反馈分辨率／噪声不支持这些判据，则候选不准入，不能把门槛改成大于步长来通过。

上述进度与误差仅为软件核验；现有 actual_qd 曾全为零而位置变化，因此不能单独以报告速度为零证明静止／限速。记录相邻位置变化、采样间隔、任务状态与速度字段，保留观测盲区。

原 movej 通路的 SDK 回执期限为 200 ms；沿用它，不修改原 speedl／PVAT 的 60 ms 期限。完成目标的 2 秒候选截止不是停止回执期限。异常仍保留原停止的 200／300／500 ms 判据，无 pause、stop_sys、恢复或自动重试。

## 6. 需要测量而不能承诺的部分

松开到到位的延迟包含输入传输、已发送小步的剩余执行、读取和稳定确认。0.5 mm 只是请求终点距离；超调、关节运动的 TCP 曲线、网络丢失和异常停止可能使实际行为不同，不能写成“松手最多走 0.5 mm”。

日志同时记录：输入发送与接收、松开接受、原生入口／返回、每次实际 TCP／关节、己方任务状态、末次稳定确认、是否请求停止及其结果。区分用户松开时间和后端收到时间；没有可信时钟对齐就不报告端到端时间。相邻采样最大残余量也不能当作未采样峰值上界。

UI 显示“待准备／可操纵／小步执行中／松开后正在到位／故障”，并明确提示“松开后完成当前小步”。独立“停止”继续请求原异常停止，不标成已经验证的即时制动。原停止故障仍是交付限制；自然结束方案不修复紧急停止可靠性。

## 7. 实现与验收顺序

1. **离线单步闭环**：注入 Fake，覆盖一笔目标→已知 ID→反馈实走→FINISHED／IDLE→稳定；证明松开无追加目标。默认拒绝真实地址和生产模式选择。
2. **离线长按与网页**：接现有摇杆，验证连续、反向、松开再按、乱序、过期、异常与逐步限额；继续使用原准备按钮，测量操作速度及剩余行程。模拟端必须模拟实际位置变化和任务完成，不能收到写入就返回成功。自有 127.0.0.1 SDK 回环核对 movej 参数、任务 ID、晚返与未知隔离。
3. **单步真机验收候选**：离线证据足够后提供具体可审阅范围，再单独请求连接／动作授权。首次只做一个有限位置目标和自然到位，不自动衔接长按。验证方向、实际位移、路径偏差、任务完成和自然静止；不重复原 speedl 80 ms 诊断。
4. **有界网页抓取**：单步和异常停止证据可支持现场风险评估后，才提出独立、有次数／时间／工作区限制的网页范围。平移、松手、自转、渐进夹爪分别验收，最后空载再轻物体。VR 复用已验收后端，仍需手柄端验证。

离线完成不能清除历史 stop_unverified，不能据此开放无人监督或持续真机控制。若首个有限位置目标的实际跟随／自然完成也不成立，报告该明确结果，重新评估原厂运动接口；不无上限创建相同微动入口。
