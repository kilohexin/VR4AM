# 停止接口核查与下一项非运动核验

## 主机核查结果

2026-09-17重新核对公开文档和本机保留的SDK 0.3.13类型声明。没有联系厂商，没有连接机器人。

- [运动接口](https://help.lebai.ltd/sdk/motion.html)：stop_move无参数，没有可配置的停止时长/减速度参数；pause_move仅声明暂停运动，不能据此认定它适合作故障保护替代。
- [系统接口](https://help.lebai.ltd/sdk/system.html)：stop_sys包含禁用关节运动；stop是取消任务后停止运动，不是一个独立、已验证的保护机制。不能通过换一个名字解决停止验证。
- SDK类型声明把actual_joint_torque/target_joint_torque标为Nm。此前报告的“单位未建立”应细化为：SDK标注单位已查到，但现场标定、停止后反馈新鲜度和物理机理仍未确认。
- SDK提供get_payload读取当前mass(kg)、cog(m)。该接口存在不证明当前配置正确，也不等于允许修改配置。

检索本地主配置、2026-09-16与09-17交付文本/JSON，没有找到get_payload输出或明确的工具质量/重心记录。这里只报告所检索范围，不声称所有历史资料都不存在。

## 明确缺口

“无负载”现场声明通常只说明未夹持工件；不能替代夹爪、转接件等末端附件的实际质量/重心资料。存在动力学配置错误的可能性，但目前没有证据认定它就是停止位移根因。

## 实验室下一项建议（资料核对，不是运动授权）

1. 先提供当前安装方式、夹爪/转接件型号，以及已有质量和重心资料；未知写未知，不要求拆卸、搬动或现场称重。
2. 查找已有原厂配置截图或导出文件，核对当前工具负载参数、安装方向。不要为了获取截图启动、复位或使能机械臂。
3. 若已有材料没有这些值，再单独安排一次已知只读接口的配置采集；必须先给定原文脚本并离线验证，不能猜RPC、扫描端口或自行调用set_payload/set_gravity。
4. 不做stop、prepare、Home、平移、旋转、夹爪或VR真机操作；不修改任何负载或保护参数。

## 当前处置

生产停止链保持不变，不把研究模型接入真机。下一次设备接触应优先补齐配置证据，而不是重复第37轮相同动作。资料核对不能证明停止已修复；若配置无异常，仍需对停止升级/关节禁用后的行为做独立工程验证。
