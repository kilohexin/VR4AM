# 停止等待期独立诊断：默认关闭的适配器接入

## 范围

本改动不是22mm位移修复，不放行真机测试。不更改200ms停止RPC等待期限、stop_sys升级条件、运动限位或停止确认判据。

RealLebaiAdapter新增构造参数 `stop_diagnostic_sampling=False`。仅显式开启且有事件记录器时，首次stop_move请求建立后启动独立读取任务。当前没有CLI、网页或配置YAML启用入口；所有既有启动路径默认不启用。不要求实验室改代码启用。

## 读取与记录

每轮按顺序读取 `get_robot_state`、`get_kin_data`、`get_estop_reason`，走同一SDK客户端但不取得运动用SDK锁。每个方法记录独立起止单调时间；这是依次采集，不是原子快照。数据保留在 `stop_diagnostic_read` 事件中，不更新 `_snapshot`、预检结果、停止确认或锁存故障。

- `outcome=sample`：三次读取完成，不代表物理静止。
- `outcome=timeout/error/cancelled`：本轮未完成；已有字段仅为部分证据，不能补齐缺失值或作为完整样本。
- `stop_diagnostic_reader_closed`：含 `unresolved_read` 与 `remote_cancel_confirmed=false`。本地取消不是远端取消证明。

单轮总读取预算100ms，完整样本间隔100ms，最多运行2秒；停止流程返回或断开时提前关闭。首次读取超时/错误后结束、不重试；每次最多一个在途读取组，每个停止事务最多一个采样器。该通道只补停止早期证据，不替代已有60秒观察。

读取清理等待50ms；close调用对采样任务等待最多100ms（不包括事件循环本身无法调度的情况）。关闭发生在停止处理之后，不插入stop_move到stop_sys之间。原停止诊断completed_ns仍表示停止处理结束，不包含诊断清理用时。

若读取忽略取消，保留任务引用与未解决状态，不发起替代读取；旧连接有未完成诊断任务时禁止重新连接，避免不断累积任务。该限制只涉及资源生命周期，不是“采样结果可决定允许运动”。正常采样不能清故障或授予运动权限。

记录通过现有有界异步诊断队列提交；磁盘/回调异常不能成为停止成功的依据，队列丢弃仍需参照diagnostics_dropped_total。协作式异步取消有界不等同底层SDK/控制盒请求已取消；同步阻塞扩展与进程强杀不在本功能保证范围。
