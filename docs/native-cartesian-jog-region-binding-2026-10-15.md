## 实现

新增 `backend/app/commissioning/native_jog_model_guard.py` 的不可变 `ModelJogRegionGuard`，并在 `NativeJogCandidateAdapter` 增加可选 `model_region_guard` 参数。

构造时绑定同一 settings/limits 对象、调用方提供的配置 SHA、记录准备关节参考、固定工具、六轴区域半径、初始偏差上限及明确时长。只接受 control 模式的字面 `127.0.0.1` 配置；工具与配置匹配，固定参考必须与配置记录准备位一致。整个关节盒须处于配置软限加余量内，理论区域的速度、加速度和参考时段检查须满足比较条件。失败发生在创建连接前。

预测在构造时计算并保存为不可变 JSON 文本；`assessment` 每次返回新副本。关节向量转为不可变元组。另用规范化配置内容哈希检测嵌套可变数组被修改，不能只依赖 dataclass 的 frozen 标记。

发送检查包括：

- 原单次消费、权限、代次、客户端、快照来源、已有故障、预检、工作区及固定截止保持有效。
- 最初绑定的 guard 不能在等待 SDK 锁期间被删除、替换或补装；settings/limits 身份及配置哈希不能变化。
- 包的时长与模型参考时长一致，速度及加速度不超过模型比较参数。
- 实际与控制器目标关节都在固定参考的初始偏差范围内，报告关节速度/加速度为零。它们只是候选起始条件，不证明物理停止。
- 当前工具与模型固定工具严格匹配；模型在实际/目标关节处的 TCP 与相应反馈满足原只读比较容差（0.1 mm、0.1°）。这只做模型数据一致性检查，不标为个体标定证明。
- 等待锁前、取得锁后、原生所有权任务的实际 SDK 入口均检查；本地模型计算之后再次检查原输入与快照期限，不能续租。

原候选的默认 None 仅保留历史合成协议用例兼容性；构造和连接的非本机地址禁用始终存在，不能借 None 开放真实地址。生产 RealLebaiAdapter、真实配置解析及网页/VR 没有新增选择器。

## 停止不依赖模型再次通过

模型只检查新运动入口。已进入 speedl 后，原 `stop_move` 事务不依赖 guard、工具或模型重新通过。专门回归在提交后删除 guard 并改变缓存工具，确认原停止仍执行。

原生速度等待 60 ms、运动新鲜度 100 ms、原停止 RPC 200 ms 及稳定验证保持不变。未知速度结果、无效/迟到 ID 和停止迟到仍保留 `stop_unverified`，不自动恢复、重试、改用 pause_move 或升级 stop_sys。进入原生前的本地拒绝，连同 disconnect 收尾，均不产生运动或停止写入。
