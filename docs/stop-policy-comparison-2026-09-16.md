# 最小停止策略离线对照结果

## 范围

仅新增 `backend/tests/prototypes/stop_policy_comparison.py` 及对应测试，复用已有 `EvidenceWindow`。无SDK、无网络、无生产代码或现场配置改动。所有输出是研究标签，不能执行stop_sys、恢复使能或授予运动权限。

## 比较内容

原策略在200ms RPC等待超时后升级。研究模型把RPC状态、连续位置/速度证据、保护审查分开：

- 有新鲜样本但尚未填满300ms窗口：仅标为研究预算内等待，不能标为已停止。
- 新鲜稳定窗口、RPC未返回：静止反馈与未解决请求并存，超时故障保留。
- 应答迟到且反馈稳定：仍保留超时故障，不自动恢复运动。
- 位移超过研究阈值、状态不符、反馈失联/过旧、硬件异常：锁存保护审查，后续稳定或迟到应答不自动撤销。
- 到达显式研究预算仍无应答或无静止窗口：保护审查，不能无限等待。

测试使用200ms应答期限、1000ms研究预算、300ms窗口、250ms样本最大间隔。后两者及漂移阈值复用旧原型。**1000ms不是建议写入真机的参数**，也未证明等待这一时长足够安全。模型没有选择实际保护动作；`PROTECTION_REVIEW`不是可替代实体保护的软件停机实现。

## 已验证

新增18项测试；原型与停止事务/失败收尾测试合计 **76 passed / 0 failed，5.26s**。测试覆盖慢应答、新鲜证据、证据缺失、丢样、先稳定后位移、迟到应答不清故障、固定预算与非法输入。额外两项预算跨事件回归先复现失败，修正后通过：迟到应答/迟到静止样本不能倒填预算截止时刻的证据。

独立审查也指出了这两项预算边界问题；修正后的最终复核因审查工作区额度耗尽中断，**不记为审查通过**。本模型仅保留为离线研究，不能据此接入生产停止链。

第20轮285个原始观察样本加stop_move应答事件按单调时间回放：

| 200ms判定 | PROTECTION_REVIEW：没有独立样本 |
| 首个观察样本 | 453ms |

一次性回放脚本保留于忽略目录 `.tmp/replay_stop_policy_round20.py`，只读本机已收到的归档，不要求实验室执行。此前已有静止窗口模型，本轮没有重写或生产化它。

## 决策

现有数据不能支持“只把200ms延长到1000ms”或“看到qd=0就不发stop_sys”的修复。也不能把没有物理输出的研究模型作为交付方案。

停止扩大原型；当前模型已经足够暴露信息缺口。下一次现场工作若安排，必须有明确的新诊断收益和独立授权，不重复原有无早期采样的+x流程。HOLD恢复亦不包含在本文件内；不能在目标/实际关节有偏差时自动启动或补发目标。

本轮没有修复真机位移，也没有新真机版本需要实验室验收；不推送测试包要求实验室再跑一轮离线核验。
