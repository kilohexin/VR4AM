## 本轮要解决的缺口

上一轮完成 13 FK 六方向局部核对，但 `assess_translation_reference` 仅在一个姿态、初始静止时比较关节速度与加速度。准备位单点通过，不能推出短段经过的其他姿态也通过。尤其 `qdd = J⁻¹(a − Jdot·qd)` 中的第二项尚未覆盖。

本轮给出针对已实现理论 MDH 模型的局部区域计算方法，作为下一步软件实现的依据。它不假定控制器采用相同个体标定，也不假定 speedl 的加速度或结束行为已经验收。

## 计算方法

在参考关节 `q0` 周围取关节盒 `|q−q0| ≤ r`，固定工具变换。`J` 的前三行为基座系 TCP 线速度，后三行为角速度。

理论 MDH 链的位置可写成固定平移经过前序旋转后的和，加上工具平移经过全部关节旋转后的项。每个单位旋转矩阵的一阶、二阶导数谱范数不超过 1。因此定义：

`L[j,k] = Σ(ell > max(j,k)) sqrt(a[ell]²+d[ell]²) + ||p_tool||₂`

得到理论模型中 `||∂J_linear[:,j]/∂q[k]||₂ ≤ L[j,k]`。角速度雅可比第 j 列只依赖其前序关节，故该列对第 k 关节的导数范数在 `k<j` 时不超过 1，其余为 0。固定工具旋转不改变基座系角速度雅可比。

令 `K=J(q0)⁻¹`、`b[i]=||K[i,:3]||₂`、`c[i]=||K[i,3:]||₂`。盒内每列的变化满足：

`ell[j] = Σk L[j,k] r[k]`

`w[j] = Σ(k<j) r[k]`

`M[i,j] = b[i] ell[j] + c[i] w[j]`

于是逐分量有 `|K·(J(q)−J(q0))| ≤ M`。若 `η=max_i Σj M[i,j] < 1`，Neumann 级数给出理论模型盒内的非奇异参考条件；不满足就拒绝给出区域预测，不通过伪逆或裁剪继续。

对任意纯平移方向，给定速度模上限 `v`，逐关节绝对速度参考量为：

`V = (I−M)⁻¹ (b v)`

对于加速度模上限 `a`，将运动中曲率项计入：

`C_linear = Vᵀ L V`

`C_angular = Σ(j>k) V[j] V[k]`

`A = (I−M)⁻¹ (b a + b C_linear + c C_angular)`

这是同一个固定工具、理论模型下的区域参考计算，包含 `Jdot·qd` 项，不依赖随机抽样作为推导依据。具体实现仍使用普通双精度数值求逆/求解，没有区间运算或定向舍入认证。

若起始关节与 q0 的差上限为 `e`，参考时长为 `t`，还须逐轴检查 `e + V t < r`，以及 V/A 不超过比较限值。该检查只适用于假设速度/加速度约束成立的参考时段；不能涵盖启动前等待、到期制动、迟到停止或控制器实际轨迹。
