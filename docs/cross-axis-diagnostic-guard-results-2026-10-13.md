# 运动轨迹核对与单次诊断横向越界门禁

日期：2026-10-13，Asia/Shanghai。开发基线：`e91e720c7fc3676ae24c5fe6446d0a9d9162065a`。本轮仅离线分析、修改和替身测试，没有新的 SDK 或机器人访问。

## 冻结现场证据核对

对当天失败会话和已冻结抓包做离线解析，49 次 IK 请求、49 个 IK 解、49 次 PVAT 指令逐项与会话记录匹配。没有按跨时钟相邻位置猜配，使用同一 RPC stream/ID 匹配请求与回复，再检查完整目标及关节数值序列。

- IK 目标 X、Y 和姿态保持固定，仅 Z 变化；已发送目标的 Z 跨度为 2.992 mm，没有发现接口把 Z 串成 X。
- 168 次 TCP 设置回复相同；170 组遥测中，法兰位姿乘该 TCP 变换与报告 TCP 的最大矩阵分量差为 `2.22e-16`。这只证明这些遥测字段的内部几何一致性，不是实物标定证明。
- 用生产 `build_pvat_point`、现场固定限值及每点记录的实际关节状态/速度参考，重建 49 点，位置、速度、加速度与实际发送值的最大数值差均为 0。
- 49 点均为 `advance`，没有本次 IK 拒绝或 catch-up；43 点使用前一指令速度，6 点使用观测速度。不能将本次横向偏移归因于历史会话的 IK 背压计数。
- 5 点的关节增量与“实际关节到 IK 解”的增量方向夹角超过 5°，最大约 14.08°。关节限速/加速度处理后的增量不保证 Cartesian 直线；这个代数指标尚不足以确定真实 X 偏移的原因。

默认视觉 FK 直接输入真机关节值并替换 TCP 后，与本次控制器遥测不一致，尚未核对关节零位及坐标约定。因此没有使用该未经校准的比较预测物理横向误差，也没有为拟合单次会话修改模型或现场配置。

## 已复现并修复的诊断缺口

当天停止请求前有 122 条运动学记录显示：非目标轴最大绝对位移超过既有 0.5 mm 容差。首条约为 0.543 mm，日志时间早于停止请求约 2,954 ms。记录采样和动作循环不是同一事件流，不能据此承诺新代码在实物上恰好提前这段时间停止。

原单次早停循环只将横向误差用于到达判定，仍可能等待目标轴进展和关节运动证据。在纯替身场景中，目标轴没有进展、横向已偏移 1 mm 时，旧实现继续等待，最终报 `smoke_early_stop_not_reproduced`。

本轮只修改 `backend/app/commissioning/smoke.py` 中显式启用 `early_stop_on_motion` 的平移诊断：

1. 非目标轴最大绝对位移超出 0.5 mm 就终止目标循环，报 `smoke_cross_axis_deviation`；不是成功的运动早停结果。
2. 保留原 Grip 松开、停止和 disarm 路径，不新增 SDK 方法、停止事务、重试或升级。
3. 先走原停止流程，再等待新增的越界记录写入；记录保存原检测时间。新增记录器背压不会被放到这次停止之前。原停止路径自身的记录和验证行为保持。
4. 边界比较只用 `1e-12 m` 数值等值容差，避免浮点减法把恰好 0.5 mm 误判超限。

普通平移诊断仍保留原横向收敛流程；连续 VR 控制、夹爪和旋转没有因此换用新运动策略。200 ms 停止期限、100 ms 输入 TTL、原稳定验证和 `stop_unverified` / `stop_incomplete` 均保持。该门禁没有解决约 621 ms 的停止回复等待。

新增 15 项替身用例覆盖 X/Y/Z 目标、正负横向偏移、现场首条越界量、略高于边界、边界与内部、停止报错/迟到、只读尾段、记录器失败和写记录期间取消；断言只调用一次停止、停止后没有 PVAT、没有 Home/夹爪/`stop_sys` 或成功结果。

- 旧实现先出现 7 个预期失败、3 通过；首版门禁后这 10 项通过。
- 初次扩大回归为 118 通过、1 失败。失败是新用例误引用记录器类，修正为实际 `_SmokeRecorder`；不是控制器或停止故障。
- 复核新增记录排序发现可等待记录才停止。加强用例先出现 1 个预期失败，确认写记录阻塞时尚未调用停止；随后改为先停止再记录。
- 最终 5 个相关文件 **120 通过，37.89 秒**，JUnit 无失败、错误或跳过。15 项新增用例包含在 120 项中，不叠加统计。

包括原普通横向收敛、低速运动证据、停止失败不得报成功，以及父/子抓包入口的材料绑定和准入回归。没有后端全集、前端构建或真实 SDK 调用。本轮由主任务静态复核，没有新增独立审查结论。
