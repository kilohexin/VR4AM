## 横向偏差的分解

对每个点，以保存 actual→IK 关节直线的投影比例 f，作如下同一模型内的精确分解：

`端点位移 = (1-f) × 已有实际位移 + f × 完整IK位移 + 关节弦段曲率项 + 点偏离关节弦段项`。

- 前六个关联运动快照的实际 X 位移为零；六个发出端点模型的最大绝对 X 位移约 **0.000220 mm**。
- 后续 **19/19** 发出端点都减小了各自保存实际快照的绝对 X 位移。
- 在实际投影比例处，关节弦段曲率项的最大绝对 X 分量约 **0.003598 mm**；点偏离弦段项最大绝对 X 分量约 **0.00002823 mm**。
- 最大受限端点 X 位移所在 submission 38：关联实际 X 为 +0.559992 mm；端点 X 为 +0.534982 mm，其中已有实际位移加权项 +0.538522 mm、IK 加权项 +0.00001285 mm、曲率项 -0.00355327 mm，偏离弦段项接近零。

因此，受限端点出现的主要 X 偏移继承了该轮运动快照中已有的偏移；本组 IK 终点误差和已计算的端点曲率贡献不足以单独解释反馈中的 0.5844 mm 峰值。这个结论限定于保存的端点与快照，不是完整控制器插补路径的证明。

另对每条 actual→IK 完整关节弦段均匀取 201 点，模型路径偏离两端 TCP 直线的最大三维距离约 0.184786 mm。这些是假设的关节直线采样，未重建控制器采用的速度／加速度插补及中途换点；不能将它与投影位置处的 X 分量混用。

本轮首个反馈中的控制器规划 TCP 已相对实际 TCP 存在 X +0.101361 mm 的差别。全窗口 actual 与同一保存记录内 controller target 的 X 差最大约 0.407830 mm；用两组保存关节角计算的模型差与反馈差，最大三维残差约 0.00000603 mm。调查重点进一步缩小到规划初始条件、PVAT 接续和实际跟踪的对应关系，尚不能分配为控制器、应用接续或机械跟踪的具体故障。

## 发送节奏与证据缺口

厂家要求相邻 PVAT 点的发送间隔小于 t，超出会自动减速；接口依次为 p、v、a、t。[厂家 PVAT 说明](https://help.lebai.ltd/sdk/motion.html#伺服运动-pvat)。固定 SDK 0.3.13 源码逐轴传入 pose/velocity/acc，并把 t 传为 duration；应用也按上述顺序传参。[固定版本 SDK 实现](https://github.com/lebai-robotics/lebai-sdk.rs/blob/79bc9bba3cc6d710c9c7d3f40f0fe01742911187/src/rpc/motion.rs#L99)。本轮未重新调用该 SDK。

保存的 24 个相邻客户端 SDK 开始间隔为 46–110 ms，原 horizon 为 80 ms，**一个开始间隔为 110 ms**。这提示接续节奏值得继续调查，但客户端调用时间不是控制器接收时间，没有协议接收边界或插补内部轨迹，不能直接宣称已证明哪一段自动减速，也不能单凭该间隔解释停止 RPC 610 ms。

下一步继续离线比较：从已有 target_q/target_qd/target_qdd 与 actual 反馈建立接续初始条件，分别检验规划起点差、跟踪差及换点时序假设；实验模型必须标明其插补假设，不能冒充控制器实现。确定可复现的应用问题后再改代码。保留原限速、加速度、背压门槛与停止锁存；现场 VR／夹爪验收仍未通过。
