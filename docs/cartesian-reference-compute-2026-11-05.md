2. 精确零速/零加速度状态只构造一个完整验证的静止保持段，代替十个重复端点；非零状态不以“近似静止”归零。
3. 显式离线选项`--braking-segment-limit 24`限制同一虚拟步内、跨需求退让的尾段构造/检查总次数。预算耗尽即拒绝未完成计划，仅能消费此前批准的尾段；不会重置预算继续搜索或安装半条轨迹。该限制是工作量约束，不是墙钟时间保证。默认不启用。
4. 朝向误差加入完整区间积分上界，取它和原位移上界中较紧者，保留原0.01rad及所有其他容差。不是减少检查采样或用端点替代路径检查。
5. 显式离线`--braking-method joint_fit`：由同一笛卡尔停止曲线的终点求解关节终点，构造保留起点P/V/A、末端零速/零加速度的完整关节多项式，切为80ms段。**每段仍重新验证原笛卡尔走廊、任务/关节速率及奇异性/分支限制**；任一拒绝就不安装该候选。它只减少重复逆解，不是未经验证的独立关节停止。默认仍为`pointwise`。

### 朝向误差上界的依据

令`E=R_refᵀ R_actual`，其角速度范数等于两条路径空间角速度差的范数。以区间中点为起点、半区间时长为`h`，SO(3)测地距离不超过：

`angle_mid + |ω_actual−ω_ref| h + (A_actual+A_ref) h²/2`。

实际角加速度上界仍来自原区间验证。参考`R=Exp(r)R0`的左雅可比是旋转矩阵的积分，因此其算子范数≤1，导数项作用于`r'`的范数≤`|r'|²/2`；可用`|r''|+|r'|²/2`包围参考角加速度，分量范围仍由Bernstein凸包计算。这是整段积分上界，不假设Euler导数等于角速度，也不假设离散点覆盖极值。浮点计算仍不构成形式化证明。

新增独立反例确认：端点姿态相同但内部转腕越界仍拒绝；非交换旋转的稠密对照均落在报告上界内。静止保持仍必须通过完整验证；注入错误的零逆解残差不能跳过新鲜FK。
