# 停止替代方案与单次暂停对照 — 2026-10-13

## 为什么现在改变推进方式

用户要求加速真机 VR 主线。现有约 621 ms 是 SDK 调用以及抓包请求—回复间隔，不是测得的机械制动时间。Wi-Fi 抓包还观察到约 1.7 ms 的 TCP ACK、同连接其它只读 RPC 通常数毫秒返回；因此继续修改 Python 锁或放宽 200 ms 期限，不能根据现有证据解决这段延迟。详见 `docs/wifi-motion-stop-results-2026-10-13.md`。

前面的入口过期、权限撤销、停止事务和轨迹数学工作提供了可复用基础，但很多连续轨迹候选仍在测试目录，尚未构成真机 VR 验收。现在优先做能改变控制方案的对照，暂停增加与本次候选无关的外围回归。

## 已核对的公开接口与选择

| 方案 | 已知依据 | 当前选择与限制 |
| --- | --- | --- |
| `pause_move` | SDK 提供无参暂停接口；控制器原生 API 标注 3.1.24 起支持 | 首选一次微动暂停对照。当前 RC 为 3.1.34，但 SDK 可调用性及运动中延迟仍须现场验证。暂停不停止任务运行，可能保留运动，不能自动 `resume_move`。 |
| 有限时长、末端零速度/加速度的轨迹 | SDK 的 PVAT 最小时间为 10 ms；连续发送间隔超出该段时间会自动减速停止。原厂轨迹说明建议首尾速度/加速度归零 | 第二路线：让轨迹有自然结束条件。断流自动减速没有公开的物理停止时间保证；不能把段长当制动上限。已有连续轨迹离线候选可复用，尚未接入生产。 |
| 控制器侧条件停止 | 原生 `movej_until` 回调约每 10 ms 检查，停止仍调用 `stop_move` | 可减少主机反应与网络依赖，但不能据此承诺消除控制器侧等待；部署控制器任务需另行设计和授权。 |

原厂公开 `stop_move` 接口没有减速度参数。`speedj`/`speedl` 的 `t=0` 会持续运动，不作为当前替代方案。短时间 `movej(t>0)` 会使 a/v 参数失效，也不能用来假定低速。

来源：[SDK 运动接口](https://help.lebai.ltd/sdk/motion.html)、[控制器原生运动 API](https://help.lebai.ltd/api/move.html)、[原厂轨迹 FAQ](https://help.lebai.ltd/en/faq/move.html)。

安装包 `lebai_sdk_asyncio` 为 0.3.13，来源指向原厂 Rust SDK。离线读取二进制发现 `pause_move` 字符串；这只说明存在符号文本，未导入原生 SDK，不能证明调用可用。专用诊断在连接后的只读预检阶段检查方法可调用性，不可用就禁止运动。

## 本轮实现

- `app.commissioning.pause_comparison.PauseComparisonAdapter` 仅由专用入口创建。生产 VR、普通 smoke CLI 与配置均仍选择 `stop_move`。
- 复用原停止优先锁、单次请求所有权、200 ms RPC 期限、300 ms 稳定窗口、500 ms 验证预算、`stop_unverified`/`stop_incomplete` 锁存。退出时复用同一暂停请求，不重发、不切换其它停止接口。
- 日志记录实际 `pause_move` 方法、`pause_move_only` 策略和锁等待，避免把暂停包装成 `stop_move`。
- 原验证仍要求无急停原因、无运行中 motion、速度与关节/TCP 漂移符合原阈值。若控制器暂停时保留运行 motion 标识，本次会验证失败；不为此放松准入。诊断成功也不证明物理停止时间或连续 VR 已可用。
- 仅诊断收尾允许与已验证锚点一致的原始 `PAUSED`/`IDLE` 状态；通用 HOLD/STOP 不当作暂停成功。PAUSED 仍不允许重新 ARMED，不自动恢复或清除旧轨迹。
- `scripts/real_robot_pause_comparison.py` 默认只预览，不建立 SDK 连接。执行需完整预览哈希、源代码/配置/SDK 哈希一致、新授权及 UTC 启动期限（不超过未来 10 分钟）；本地已有 RPC 连接就拒绝。输出目录原子创建，同一次连接失败也消耗尝试。
- 固定一次 +Z 3 mm，原低速上限、原横向 0.5 mm 偏离保护，取得原运动证据后早停，两秒只读尾段。无 Home、准备位姿、夹爪、复位、恢复、自动重试和抓包。

不运行 Pktmon，不修改残留筛选器，不需要管理员确认。这次只比较 SDK 调用和原状态验证；没有线上的请求—回复拆分，必要时另行决定抓包。
