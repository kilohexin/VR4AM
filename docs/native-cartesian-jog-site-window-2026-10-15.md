## 交付状态

已按用户认可的三项计划实现共享发送核心、显式范围/客户端/执行器，以及默认只预览的 CLI。新增路径没有注册到生产网页或 VR。此阶段只有离线开发授权，未连接真实机器人、未发送现场命令、未推送。

入口为 `scripts/real_robot_native_jog_window.py`。固定候选：基座 +Z、5 mm/s、10 mm/s²、80 ms，角速度为零。仅一次连接、一次 speedl，实际进入原生速度请求后才允许唯一一次原 stop_move。没有 Home、准备位、夹爪、恢复、复位、自动重试或 PVAT 回退。

`complete` 只表示本次软件流程、原停止事务和诊断尾段满足检查；不是物理停止或连续控制验收。`hardware_verified`、`joint_bounds_verified`、`braking_verified`、`continuous_control_admitted` 始终为 false。原 621 ms 现场停止问题没有因本机回环而被宣称解决。

## 实现要点

- 旧 `NativeJogCandidateAdapter` 和公开模型 guard 仍只接受 127.0.0.1。新现场类要求独立 SiteJogScope、同一范围身份的代理和显式工厂，没有 allow_real 开关。
- 全部 SDK 读取，包括观察器的独立 reader，共用 256 次实际入口预算；FK 和倍率各最多一次，IK 为零，总逻辑调用最多 259。必须读取倍率为 100，不修改倍率。
- FK 后获取新的六字段并行快照。关节和工具输入必须完全一致，反馈与 FK 在 0.1 mm/0.1° 内；实际写入前再次检查 FK 年龄和原 100 ms 新鲜度。不能刷新计算或重新创建包续租。
- 总预算 20 秒，连接最多 5 秒，普通读/FK 当前均最多 200 ms（FK 比计划的一秒上限更严格）。运动入口至少剩余五秒收尾预算。授权检查本身耗时后仍复查截止。
- 速度等待 60 ms、停止 RPC 200 ms、稳定 300 ms、停止验证 500 ms，均沿用原限制。计时使用独立 QPC 循环，参考结束锚定实际原生 speedl 进入时间。
- 观察器最多一次中点读，最多 50 ms 且不超过参考结束。到点同步撤销，不等读取或取消确认才停止。未知结果永久保留，迟到结果不能改写已封存报告。
- 已进入速度后，源码变化或运动授权失效仍保留唯一停止权限。未进入原生速度时不补发停止。停止失败仍作为首要错误，诊断尾段不能提升成成功。
- CLI 绑定配置、13 FK 冻结报告及 admission、显式规划范围、运行代码和固定 SDK。默认不初始化 SDK、不占用输出目录。执行须独立预览 SHA、专用确认文本和十分钟内绝对 UTC 启动有效期；一次输出目录即使失败也不能重用。

## 实施裁定与审查限制

1. 保留用户指定的当前特性分支和冻结资料；未另建/重置检出。Bash 帮助脚本不可用，使用本机账本。代价是审计记录依靠该账本与提交；本地证据保留。
2. 按 AGENTS 运行定向回归，不跑全集。独立审查此前因工作区额度不足未执行，本轮没有重复派发；只有作者复核，不冒称独立审查通过。代价是仍可能存在作者盲点，应在合并/部署前补审。
3. SiteJogClient 复用 FiniteScopeClient 的并行读取所有权，显式拒绝继承的 PVAT/IK 等路径，以免复制一套并发所有权逻辑。潜在风险是继承暴露额外接口，已用写入拒绝、全局读取预算和入口计数回归约束。
4. 文件检查放在实际 SDK 读入口及运动锁/写入口，嵌套所有权辅助函数只做绑定检查。热路径核对配置/批准字节与来源/运行代码元数据；冷路径与实际写前做完整 SHA，随后仍检查原截止。元数据不能防御刻意保留元数据的篡改，实际写前的完整 SHA 因而保留；被篡改进程不在此进程内防御模型内。
5. FK 当前使用 200 ms 读上限，比计划最多一秒更严格；代价是慢 FK 会提早拒绝，无自动重试。
6. 私有候选工具和工作区变更明确列入未来批准范围，不修改既有现场设置。若这些候选不符合现场要求，入口必须重新生成范围，不能直接执行。
