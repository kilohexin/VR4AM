# VR4Arm 项目组会进展汇报

汇报日期：2026 年 9 月 10 日  
本周重点：真机运动与停止异常排查、控制逻辑修复、实验观测能力完善  
证据范围：截至 2026 年 9 月 9 日的仓库提交与实验交接记录。文中的软件测试数量为对应版本已记录的结果，不代表本报告编写时重新运行的测试。

## 一、总体进展

项目已经打通 VR 仿真与真机控制的软件链路，当前处于小幅度、单轴真机验证阶段。本周的重点是通过现场测试查清运动和停止异常，为后续连续遥操作建立可靠依据。

目前已实现：

- VR 手柄相对位姿控制、机械臂状态反馈和夹爪交互。
- Home、安全停止、软边界、故障处理以及诊断日志。
- 仿真端离线演练与自动化验证。
- 真机端只读预检、准备位运动、小幅单轴测试及实验记录。

此前 `+x / -x / +y / -y / -z` 五个平移方向取得了现场通过记录。这些记录具有版本、位形和测试条件限制，不能直接外推为整个工作空间或连续运动均已通过。

完整多轴运动、运动后停止稳定性以及 Quest 连续真机遥操作仍未完成验收。

## 二、本周主要工作与结果

### 1. 修复轨迹指令间隔过长时的速度历史问题

前期已将 IK 解连续性与机械臂跟踪滞后分开处理，并增加回压机制。本周继续排查实际运动的到位精度。

在一次请求 `+5 mm` 平移的实验中：

- TCP 目标没有超过 `+5 mm`。
- 最终实测位移为 `+5.792 mm`，日志峰值约为 `+5.905 mm`。
- 轨迹时长为 `80 ms`，但当时记录的发送完成事件间隔约为 `125～172 ms`。

通过现场关节快照复现发现：机械臂实际已经减速，但程序仍沿用上一条指令的速度进行加速度限幅，生成的关节位置越过了完整 IK 目标。

修复后，程序仅在上一段轨迹仍有效时保留指令速度历史；轨迹过期后，使用当前实测关节速度重新计算。修改覆盖正常目标推进和回压追赶两条路径。

**结果：修复后的一次 `+5 mm` 真机平移复测通过。** 这证明已复现问题得到针对性处理，但不构成任意位形、任意轨迹均无过冲的保证。

### 2. 增加分段计时，定位发送节奏瓶颈

平移复测通过后，日志仍显示控制节奏存在问题：

- 23 个成功 PVAT 调用起点间隔全部超过 `80 ms`。
- 间隔范围为 `93～219 ms`，平均约 `138 ms`。

因此，单次到位精度通过，还不足以说明连续跟随平滑性达到要求。上述数据来自单动作 smoke 测试，不能直接等同于 VR 运行时性能。

本周新增分段计时，分别记录状态快照读取、SDK 锁等待、候选 IK 计算、PVAT 发送及 smoke 循环耗时。后续 32 次日志中，两处 SDK 锁等待平均合计约 `56.1 ms`，提示状态读取和命令之间的竞争值得优先分析。

**作用：为后续减少重复读取、改善任务调度提供量化依据。** 目前尚不能宣布发送频率问题已经解决，也不能将全部未解释耗时归因于 IK。

### 3. 加固停止判定，补齐停止诊断

9 月 9 日的一次实验出现 `sdk_timeout:stop_move`。原会话缺少后续 `stop_sys` 调用的完成或超时记录，不能仅根据停止确认字段倒推兜底调用成功。

退出阶段原始状态仍为 `STOPPING`，旧逻辑却仅根据关节速度连续低于阈值就确认停止。随后独立探针与会话末值相比，记录到：

- J2 关节位置相差约 `1.5°`。
- TCP x 位置相差约 `18.1 mm`。
- 现场确认中间没有人工移动、xLab 操作或手动启停系统。

两份离散记录不足以确定变化发生的时刻，也无法独立区分实际运动、反馈延迟和系统停止过程的影响。

本周已完成的代码改进包括：

- 停止确认联合检查原始控制器状态、急停原因及未结束的运动任务。
- 在连续验证窗口内，同时检查关节速度、关节累计位移和 TCP 累计位移。
- 防止 `STOPPING` 等状态仅凭低速度读数被判定为停止成功。
- 增加停止接口及兜底调用的起止时间、结果和验证样本记录。
- 隔离诊断写入，避免日志处理阻塞停止与兜底流程。

**结果：已修复“过早确认停止”的软件漏洞；停止接口超时与约 `18.1 mm` 位置差异的根因仍在调查。** 停止确认与下一次运动就绪也已分别判断，确认静止不自动代表可以继续运动。

### 4. 新增停止后观察，建立静止基线

为补齐旧会话退出后的记录空白，本周增加可选的停止后只读观察，将停止验证及随后状态采样保存在同一会话中。

最新已核对的 Home 静止停止基线为：

| 指标 | 记录结果 |
| --- | --- |
| `stop_move` 返回时间 | `16 ms`，无 `stop_sys` |
| 停止验证样本 | 6 个 |
| 停止后观察时长 | `60.015 s` |
| 观察样本 | 288 个 |
| 原始控制器状态 | 观察样本均为 `IDLE` |
| 读取错误／记录丢失 | 均为 0 |
| 相对首个观察样本的最大关节变化 | 约 `0.0055°` |
| 相对首个观察样本的最大 TCP 平移变化 | 约 `0.063 mm` |
| 最长成功采样间隔 | `281 ms` |

这建立了可用于后续比较的 Home 静止基线。记录中有 9 个样本出现非零速度读数，其来源尚未确定，不能直接认定为噪声或真实微动。

观察属于持续的离散采样，并非无间隙记录；完成观察不等于通过运动后停止验收，也不证明此前位置异常已消失。

## 三、为什么本周测试投入了较多时间

### 1. 真机链路需要逐层验证

数学上可解、指令成功返回、机械臂实际到位、停止后保持稳定，是不同的验证目标。真实系统还受到控制器状态、SDK 调用、网络与调度延迟、运动历史和机械臂位形的共同影响。

本周的测试揭示了这种层次关系：平移到位复测通过后，仍发现发送间隔超过轨迹时长；速度读数接近零时，原始控制器状态仍可能是 `STOPPING`。每个结论都需要匹配相应证据，不能由一个成功字段代替整个过程的验证。

### 2. 每轮测试都包含现场反馈与软件修复闭环

完整过程包括版本和配置核对、只读预检、受控单动作测试、停止确认、日志回传、逐事件分析、问题复现、代码修复、软件回归和现场复测。

为了区分原因，需要逐步控制位形、运动方式和软件版本等因素。本周新增的下一轮计划，就是先比较同版本下 Home 与准备位的停止基线，再考虑运动后的停止观察。

### 3. 早期证据存在空白，需要先补观测能力

此前只能从两份相隔一段时间的记录中发现位置不同，无法还原中间过程。为此，本周补充了分段计时、原始控制器状态、停止调用结果和停止后采样。

这些工作提高了每次实验的信息量，使后续测试能够回答“时间花在哪里、状态何时变化、位置何时改变”，减少缺少依据的反复试探。

### 4. 耗时主要来自实验闭环，自动测试提供快速复核

最新版本文档记录完整后端回归为 **708 项通过，耗时约 87 秒**，其中新增 12 项停止后观察相关测试。完整回归覆盖读取失败、时间边界、队列丢失、取消、故障锁定及只读采样等情况。

从工作内容看，时间投入主要集中在现场复测、证据补齐和因果分析。现有材料没有完整工时统计，因此不对各环节耗时比例作定量判断。

## 四、测试结果的重要性及其作用

| 测试发现或结果 | 支持的结论 | 对后续工作的作用 |
| --- | --- | --- |
| 5 mm 指令出现过冲，并用现场快照复现 | 过期速度历史存在具体计算缺陷 | 指导针对性修复，建立可重复的回归用例 |
| 修复后单次平移复测通过 | 该条件下的到位表现得到验证 | 为后续受控实验提供依据，保留适用条件 |
| 成功平移中的发送间隔仍偏长 | 到位精度与连续跟随性能需要分别评价 | 明确状态读取、SDK 锁竞争及调度优化方向 |
| `STOPPING` 曾被误判为停止成功 | 单靠低速度读数不足以确认停止 | 完善状态、速度和累计位移的联合判定 |
| 两份记录间出现约 18.1 mm 位置差异 | 现有证据不足以解释停止后的变化 | 暂缓扩大运动测试，补齐停止后时间线 |
| Home 停止后取得 60 秒观测基线 | 获得特定位形下可比较的静止记录 | 为准备位及运动后停止实验提供对照 |
| 新增场景进入自动化回归 | 已知异常可在软件修改后被重复检查 | 降低后续修改引入同类问题的风险 |

测试结果既用于判断当前功能是否满足条件，也直接决定代码修改方向、下一轮实验范围和后续功能的推进顺序。失败记录保留了系统边界与异常触发条件，是定位原因和建立回归检查的重要材料。

## 五、当前未完成事项与下一步计划

当前仍需解决：

- `stop_move` 超时及停止后约 `18.1 mm` 位置差异的原因。
- PVAT 发送节奏偏慢及其对连续跟随的影响。
- 准备位和运动后停止的稳定性验证。
- 完整多轴运动、Quest 连续真机遥操作及完整硬件验收。

`+z` 的最新只读诊断已在该准备位找到 IK 解，因此不宜继续笼统表述为“完全无解”；但存在 IK 解不等于路径、碰撞和真实运动验收已经通过。

下一步按现有交接计划推进：

1. 在同一软件版本下，建立准备位的停止后 60 秒观察基线。
2. 比较 Home 与准备位的状态、位置变化和读取延迟，同时保留准备位运动历史这一差异，避免单次实验过度归因。
3. 基线核对后，再单独安排同准备位的小幅 PVAT 运动及停止后观察。
4. 根据分段计时定位重复读取和任务竞争，再进行针对性调度优化。
5. 将新增现场发现固化为回归测试，逐步推进多轴和连续遥操作验收。

## 六、组会口头汇报结语

本周已经修复可复现的过期速度计算问题和停止误判漏洞，并建立了更完整的诊断与停止后观测能力。测试投入的价值体现在：把现场异常转化为可复现的问题、可验证的修复和有依据的下一步实验。当前单次平移取得了复测进展，Home 静止停止也已有观测基线；停止超时及异常位置差异仍在调查，后续将先完成准备位对照，再推进运动后停止和连续遥操作验证。
