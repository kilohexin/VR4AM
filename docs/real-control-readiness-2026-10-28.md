# 真机空载验收准备与仿真差异

更新：2026-10-28。本轮仅离线检查与注入客户端测试，没有加载原生 SDK、连接真机或签发新的现场执行授权。

## 可以何时开始

机械臂恢复可用、操作者到场并批准具体范围后，可以开始下一轮**网页真机空载验收**。不需要等待物理引擎；当前阶段还不能把完整 VR 抓取或真实夹物认定为验收通过。日历日期取决于设备恢复与现场可用时间，离线回归不能预测该轮一定通过。

当前网页入口已具有独立解锁、准备位、2 mm 有限位置目标、松手不续发、渐进夹爪及默认关闭的工具俯仰能力。正常释放不强制发 stop_move，异常仍保留原停止事务和 stop_unverified。停止延迟不再阻塞正常释放方案开发，但历史异常停止未确认不能清除或标成已解决。

## 不能直接把 Docker 结果替代的部分

| 项目 | 已通过的 Docker 路径 | 下一轮真机路径 |
| --- | --- | --- |
| 准备位/工具 | 独立零 TCP 与仿真准备位 | 保留现场保存的准备位与工具，必须新读核对 |
| IK / FK | 原厂 IK；启动三组原厂 FK 比对后本地 FK | 保留原厂 IK 和逐步原厂 FK，不把未标定理论模型直接当真机 FK |
| 夹爪 | 本地虚拟夹爪，无接触物理 | 原厂实际夹爪反馈和命令；真实响应、初始化状态与力度待验收 |
| 正常松手 | 当前有限目标自然到位，不追加 | 同一控制契约，实际余量和到位效果待测 |
| 异常停止 | 仿真专用 1000 ms 回复 / 2000 ms 验证 | 原 200 / 300 / 500 ms 判据及未知锁存保留 |
| 方向界面反馈窗口 | 500 ms | 原 100 ms |
| 预计段耗时 | 4.8 s，既有 5 s 到位窗口 | 原 1.8 s 规划估计；既有 5 s 粗抓取到位窗口 |
| 页面轮询让行 | Docker 专用规划→发送入口短窗口 | 不擅自迁入；真实锁竞争和延迟仍需现场证据 |
| VR | 合成输入整链通过 | HTTPS/LAN、头显输入/呈现及真机动作尚待验收 |

这些差异影响真机时序与操纵连续性，不能用修改环境标签、复制仿真时限或模拟夹爪来宣称真机已通过。

## 下一次现场建议一次批准的完整网页范围

在执行前生成绑定当时源码、配置、SDK 和准备记录的新预览；本文件不是授权材料，不带有效期，也不会连接机械臂。

1. 只读核对当前状态、工具、保存准备位与可用夹爪反馈；不符合就结束。
2. 解锁仅授予权限；操作者独立点击进入准备姿态，核对真实运动及到位。
3. 先一个有限平移目标并松手，确认不续发和自然到位；通过后才进行少量正反平移/升降和 0.5° 空载俯仰。
4. 空载验证夹爪渐进开/关及松开保持，不夹取物体；初始化异常、命令超时或结果未知都结束，不自动初始化、复位或重试。
5. 正常关闭并保存真实位移、目标余量、时延、错误及操作者目视收尾。出现故障或停止未确认即结束本轮，不自动接下一动作。

建议复用已有网页范围的上限：一次连接、最多 5 分钟，准备及平移合计不超过 21 次 movej、100 次夹爪目标（力请求上限 30%）、4 次原停止；仍限于保存准备位附近既有软件工作区。实际申请时应按当日任务减少次数，明确包含俯仰；无 Home、恢复、复位、物体或 VR。这些是待审范围建议，不是已批准动作。

网页空载通过后，再安排真实头显与同一有限目标控制链验收；轻物体抓取留在空载和夹爪结果明确之后。头显佩戴与物理抓取不能通过纯软件测试补齐。

## 本轮离线工作及证据

- 真机适配器、网页启动预览、准备调度与输入过期相关 32 项定向回归通过；只注入内存客户端，没有原生 SDK 或网络连接。
- 旧完整流程用例只发一次有限 held，而循环仅续发中性的 VR 健康帧；规划稍慢就按原 100 ms 规则过期。旧用例还以“第三次写入”推断平移，可能把异常 stop_move 误认成 movej，随后只显出 authority_revoked。
- 测试驱动现在按产品网页的独立 20 ms 采样续发新的有限 held；在实际第二个 movej（第一个为准备）进入后释放。断言故障为零、无额外停止、自然到位后仍能两次操作夹爪。
- 新增 120 ms 规划等待场景：原驱动失败，持续新输入驱动通过；单独的输入过期仍故障/停止回归通过。未改动产品代码或任何保护判据。没有把测试驱动修复称为真机时序修复。
