# 停止后原始运动数据补齐

## 本轮变更

开启既有 `--stop-rpc-diagnostics` 时，`stop_observation_sample.state.raw_kinematics` 保留该次已有 `get_kin_data` 返回的完整字典。典型字段包括实际/目标关节力矩、位置、速度、加速度与TCP；SDK未返回的字段保持缺失，不推断为零或正常。

原始数据在已有get_kin_data完成后、下一次SDK await之前复制，防止SDK复用嵌套数据导致历史记录被改变。关闭诊断时不增加该字段，也不做该复制。正常控制采样不收集这份额外副本。

没有新增RPC，没有更改采样间隔、停止超时、故障锁存、停止升级、运动权限或现场配置。力矩数据是SDK反馈，不是独立测力、关节使能或制动器状态证明；数据字段之间不是跨RPC原子快照。

独立早期读取器的2秒是运行上限，不是保证运行满2秒；停止函数收尾时可提前关闭。原有60秒观察继续运行，此补丁让后段也能保留原始运动字段，不通过延长并发读取来覆盖后段。

## 下次现场目标与VR阶段的边界

目标是在一次现场工作窗口内推进，不再拆成多轮材料核对；但本补丁只是补证据，不自动放行任何真机动作。

1. 现场状态、安全条件和实际源代码版本确认后，由单独指令安排有新增早期诊断和完整尾部数据的受控停止验证。HOLD不等同IDLE；启动/复位/准备位恢复不得隐含在测试命令中。
2. 一旦发生停止未确认、异常位移或反馈失效，停止后续动作，按现场安全流程处置，保留证据；不得为完成观察期延迟必要处置。
3. 只有停止缺陷被修复且对应真机验证通过，才进入低速、限定范围、无负载的VR最小验证。单次未复现不能代替修复验证。
4. VR第一阶段仅平移及Grip松开停止；旋转、夹爪、Home和其它复杂动作后置。停止、断连及重按Grip行为须明确验证；不能从本文件直接推导可执行命令。

因此可以争取下次进入VR，但不能承诺：若停止缺陷仍在，下一次只能完成诊断，不能带故障交付VR真机功能。
