## 运动入口材料修复

沿用既有 `motion_stop_wire_capture.py` / `real_robot_wire_stop.py`，动作仍固定为 +Z 3 mm 目标、取得运动证据后早停、2 秒只读尾段。低速上限、停止期限、失败锁存和无自动重试规则保持；没有准备位姿、Home、复位或夹爪目标。

新增或修复以下绑定：

- 预览明确显示目标 IP 和固定 UTC 有效期；父、子入口传递相同有效期。修改独立 CLI 时间不能给旧批准续期。
- 运行材料包含当前 SDK 包入口 `__init__.py` 和 `.pyd` 二进制散列。
- 真实执行限定仓库 `.venv` 解释器。在本机工具执行前及实际 SDK import/init/connect 前，检查必需 SDK 文件存在、尚未加载、实际包与 extension 搜索来源符合固定安装目录。来源检查不导入或初始化 SDK。

旧预览与新源码/字段不一致，不能复用。正式批准预览将通过 Python CLI 生成并绑定当前材料；默认 Windows launcher 预览仍可不带有效期，此类预览不能执行。实际 Execute 分支原来就传递有效期。

## 单次夹爪诊断修复

扩展回归发现，通用 commissioning 的夹爪分支等待了 100 ms 指令周期，却沿用等待前的虚拟控制帧；原 100 ms VR TTL 会拒绝该请求。

修复仅在该独立、明确夹爪动作的诊断中，于等待及 scope 检查后发布当前动作的虚拟帧，再发显式夹爪命令。先递增序号，确保命令失败后也可发布不同序号的 Grip 松开帧。没有延长 TTL，也没有刷新真实头显输入或修改网页控制路径。新增延迟 120 ms 的用例仍保持拒绝和零夹爪 SDK 写入。
